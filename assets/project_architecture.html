Chat-Langchain-Study 项目架构图

前端 UI 层
Next.js + React + TailwindCSS 实现网页界面，用户输入、展示对话结果。
  • HTML / CSS / JavaScript / 图片资源
  • Next.js 页面与组件
↓
接口交互层
前端通过 HTTP 请求（POST/GET）与 FastAPI 后端交互，发送问题、反馈、获取 trace 链接。
  • API 路由：/chat, /feedback, /get_trace
  • Pydantic 定义数据结构（如 ChatRequest, SendFeedbackBody）
↓
业务逻辑层
FastAPI 负责路由分发，调用 LangChain、LangSmith、Weaviate 等 AI 组件，处理对话、反馈、溯源。
  • FastAPI 框架
  • LangChain 对话链路（chain.py）
  • LangSmith 客户端（trace、反馈）
↓
数据存储层
嵌入数据、文档、反馈等存储于数据库和向量库，支持去重、检索。
  • SQLRecordManager（ORM，支持 SQLite/Supabase/Postgres）
  • Weaviate（向量数据库）
↓
服务运行层
Uvicorn 启动 FastAPI 服务，支持本地或 Docker 部署。
  • Uvicorn
  • Docker（可选）
